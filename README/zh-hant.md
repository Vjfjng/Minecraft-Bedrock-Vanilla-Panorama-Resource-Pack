# Minecraft基岩版原版全景圖資源包
 要求最低版本：1.13.0

 建議版本：最新版（[見此](https://zh.minecraft.wiki/w/Template:Version/doc)）

 # 這裡有哪些全景圖？
 所有Java版、基岩版和教育版的全景圖。

 **請注意：基岩版使用HDR格式儲存Vibrant Visuals的全景圖，而本資源包使用的是轉換後的PNG格式，故可能存在效果不盡相同的情況。  **

 # 如何使用？
 從[“Release”](https://github.com/Vjfjng/Minecraft-Bedrock-Vanilla-Panorama-Resource-Pack/releases)下載，並在Minecraft：基岩版中開啟，從設定處將其活化為全域資源。
