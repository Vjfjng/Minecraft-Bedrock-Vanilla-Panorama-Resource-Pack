# *Minecraft: Bedrock Edition* Vanilla Panorama-Ressourcenpaket
Mindest version erforderlich: 1.13.0

Empfohlene Version: Neueste Version ([siehe hier](https://zh.minecraft.wiki/w/Template:Version/doc))

# Welche Panoramen sind enthalten?

Alle Panoramen für die *Java Edition*, die *Bedrock Edition* und die *Education*.

**Hinweis: Die *Bedrock Edition* verwendet das HDR-Format für lebendige Panoramen, während dieses Ressourcenpaket das konvertierte PNG-Format verwendet. Daher können die Effekte abweichen.**

# Anwendung

Laden Sie das Ressourcenpaket von [„Release“](https://github.com/Vjfjng/Minecraft-Bedrock-Vanilla-Panorama-Resource-Pack/releases) herunter, öffnen Sie es in *Minecraft: Bedrock Edition* und aktivieren Sie es in den Einstellungen als globale Ressource.
